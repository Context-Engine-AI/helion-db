# Setup

## HelixCLI installation

```bash
cargo install --path helix-cli
```

## Install Helix

```bash
helix install
```

This example assumes you are working from the GPL fork repository checkout rather than an upstream hosted installer.

# Run Queries

Take a look at the queries in `./helixdb-cfg` to see what is being used.

> cd into `helix-demo` if you haven't already
```bash
helix deploy --local
```

#### Now you're ready to use the notebook!
