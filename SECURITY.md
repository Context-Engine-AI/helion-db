# Security Policy

## Supported versions

Security fixes are developed against the current `main` branch and the latest
published release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include affected versions, reproduction steps, impact, and any proposed
   mitigation.

If private vulnerability reporting is temporarily unavailable, contact the
maintainers through the private contact method published on the Context Engine
AI GitHub organization profile.

Please do not include real credentials, customer data, or production exports in
the report. Use minimal synthetic reproductions whenever possible.
